# AmisterStats 手動テスト仕様書

## テストの種類と分担

| 種類 | ツール | カバー範囲 |
|---|---|---|
| **自動テスト（Jest）** | `npm test` | JS純粋関数（エスケープ・フェーズ計算・ラベル生成） |
| **手動テスト（本書）** | ブラウザ操作 | UI表示・フォーム送信・DB連携・タブ切り替え・モーダル |

> 自動テストと手動テストは補完関係にあります。どちらも必要です。

---

## テスト環境

- URL: `http://xs228925.xsrv.jp/Amister_stats/AmisterStats/`
- 推奨ブラウザ: Chrome / Safari（iOS含む）
- テスト前提: DBに接続できている（DBエラーが表示されていない）

---

## 事前準備

テストを始める前に、以下の**最低限のデータ**を用意してください。

1. **マスター登録 → 選手タブ** で選手を2名以上登録
2. **マスター登録 → 行為タブ** で行為を2件以上登録（ポイント正・負それぞれ1件ずつ）
3. **マスター登録 → 試合タブ** で試合を1件以上登録

## 補足: 自動テストと手動テストの違い

```
【自動テスト（Jest / npm test）が確認できること】
  ✅ escHtml関数がXSS文字を正しくエスケープする
  ✅ スパイダーチャートのOF/DF切り替えロジック
  ✅ 試合種別ラベルの生成ロジック

【手動テスト（本書）が確認できること】
  ✅ ブラウザでUI要素が正しく表示・操作できる
  ✅ フォームがDBにデータを保存できる
  ✅ タブ・モーダルなどのインタラクションが動作する
  ✅ サーバーとAPIが正しく連携している
  ✅ モバイル端末での操作感
  ✅ フィルターが実データに正しく適用される

→ 両方のテストを組み合わせることでアプリ全体の品質を担保できます。
```
